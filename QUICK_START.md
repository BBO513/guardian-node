## 🔧 Customization

### Change Colors (if needed):
Edit `guardian_gui.py` → `ThemeConfig` class

### Adjust Touch Targets:
Look for `setMinimumHeight()` calls (currently 50-55px)

### Modify Animations:
Find `QPropertyAnimation` sections (currently 300-800ms)
