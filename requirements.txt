# 1. BASIC INSTALLATION (Core + GUI + LLM)
#    pip install -r requirements.txt
#

#    pip install pyyaml psutil requests cryptography llama-cpp-python PySide6
#
# 3. FULL INSTALLATION (All features)
#    Uncomment optional dependencies above and run:
#    pip install -r requirements.txt
#
# 4. SYSTEM DEPENDENCIES
#    Some packages may require system-level dependencies:
#    
#    Ubuntu/Debian:
#      sudo apt-get install portaudio19-dev python3-dev
#    
#    macOS:
#      brew install portaudio
#    
#    Windows:
#      Most dependencies are bundled with pip packages
#
# 5. TROUBLESHOOTING
#    - If llama-cpp-python fails to install, try:
#      pip install llama-cpp-python --no-cache-dir
#    
#    - If PySide6 has issues, try:
#      pip install PySide6 --upgrade
#    
#    - For voice features on Linux without audio:
#      pip install pyttsx3 speechrecognition (skip pyaudio)
#
# 6. DOCKER INSTALLATION
#    Dependencies are handled by Dockerfile
#    No manual installation needed when using Docker
